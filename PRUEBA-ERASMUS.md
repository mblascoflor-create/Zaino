# Primera prueba con un grupo Erasmus
Convocad a un grupo que ya esté pensando en una escapada por Italia. Usad la versión compartida cuando esté publicada y conectada. El HTML local sirve para ensayar en un dispositivo.

## Texto para el grupo
«¿Probamos Zaino para nuestra próxima escapada? Cada uno responde desde su móvil. Luego miramos qué ruta propone y decidimos qué conservar. [Enlace de invitación del viaje]»

## Recorrido
La persona que organiza crea el viaje e invita al grupo. Los demás entran desde el enlace y responden a su ritmo. Sin explicarles los botones, pedidles que encuentren una parada que encaje con sus gustos y cambien otra. Preguntad después del viaje qué parada hicieron de verdad.

| Dato que anotar | Resultado |
|---|---|
| Invitaciones enviadas / personas que abrieron el enlace | |
| Personas que empezaron / terminaron las preguntas | |
| Primera pantalla donde alguien pidió ayuda | |
| Parada que conservaron y motivo, en sus palabras | |
| Cambio que intentaron y si encontraron alternativa | |
| Parada realizada (preguntar después del viaje) | |

Anotad totales de grupo. Los presupuestos individuales y las fechas privadas no hacen falta para evaluar la prueba.
